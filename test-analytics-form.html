AnalyticsForm Component Testing Guide

Option 1: Temporary Integration in App.jsx

To test the AnalyticsForm component, you can temporarily add it to App.jsx:

  1. Import the component: 
    import AnalyticsForm from './components/AnalyticsForm'
  2. Add it to the render (e.g., in the Analytics tab placeholder): 
    {activeTab === 'analytics' && (
  <div className="tab-panel">
    <AnalyticsForm 
      onSubmit={(request) => console.log('Analytics Request:', request)}
      loading={false}
      initialSeriesIds={fredData ? [fredData.series_id] : []}
    />
  </div>
)}
  3. Start the frontend dev server: npm run dev
  4. Navigate to the Analytics tab

Option 2: Manual Testing Checklist

Test the following scenarios:

  • Series ID Input:
    • Enter single series: "GDP"
    • Enter multiple series: "GDP, UNRATE"
    • Test with spaces: "GDP, UNRATE, CPIAUCSL"
    • Test empty input (should show error)
    • Test invalid format (should show error)
  • Analytics Types:
    • Select/deselect each checkbox
    • Select multiple types
    • Submit with no types selected (should show error)
    • Select "Correlations" with only 1 series (should show warning)
  • Common Parameters:
    • Change limit value (test min: 1, max: 1000)
    • Toggle sort order (asc/desc)
    • Toggle use cache checkbox
  • Moving Averages (conditional):
    • Select "Moving Averages" checkbox (parameters should appear)
    • Change window size (test 2-365 range)
    • Toggle between SMA and EMA
    • Deselect "Moving Averages" (parameters should hide)
    • Submit with Moving Averages selected but invalid window (should show error)
  • Time Aggregations (conditional):
    • Select "Time Aggregations" checkbox (parameters should appear)
    • Change period dropdown (daily, weekly, monthly, quarterly, yearly)
    • Change function dropdown (mean, sum, min, max, first, last)
    • Deselect "Time Aggregations" (parameters should hide)
  • Form Submission:
    • Click "Run Analytics" with valid data (should call onSubmit callback)
    • Test with loading=true (form should be disabled)
    • Click "Reset" button (form should clear)
  • Initial Values:
    • Test with initialSeriesIds prop (should pre-fill series input)

Option 3: Browser Console Testing

Once the component is rendered, you can test it in the browser console:

  1. Open browser DevTools (F12)
  2. In the Console tab, you can interact with the form
  3. Check form validation by submitting with invalid data
  4. Monitor the onSubmit callback to see the request object

Option 4: React DevTools

Use React DevTools browser extension to:

  • Inspect component state
  • View props
  • Monitor state changes as you interact with the form

Expected onSubmit Callback Data

When you submit a valid form, the onSubmit callback should receive an object like:

{
  series_ids: ["GDP", "UNRATE"],
  analytics_types: ["statistics", "growth_rates"],
  limit: 100,
  sort_order: "desc",
  use_cache: true,
  // Conditional parameters (only if relevant analytics type is selected):
  moving_average_window: 7,        // if moving_averages selected
  moving_average_type: "sma",      // if moving_averages selected
  time_aggregation_period: "monthly",      // if time_aggregations selected
  time_aggregation_function: "mean"        // if time_aggregations selected
}
